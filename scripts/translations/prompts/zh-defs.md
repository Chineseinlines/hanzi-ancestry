# 中文释义翻译指南（zh-def）

你的任务：把 JSON 文件中每个汉字的英文释义（d 字段）翻译成中文释义，并把词源提示（h 字段）翻译成一句中文白话。逐键填写 chunk 文件里对应条目的 d 和 h 字段（保持 JSON 格式，只改值）。

输入文件：`<CHUNK_PATH>`（scripts/translations/chunks/zh-def-NNNN.json）
输出：用 Edit/Write 工具**原地写回同一个文件**，把所有空值填上。不要改动键的顺序，不要新增或删除键。

## 规则

1. **词典体**：义项用「；」分隔（不用逗号），风格参考《现代汉语词典》。
2. **义项一一对应**：英文 d 字段的义项个数与顺序要和你的中文一一对应，不增删、不合并。例：
   - `bright, clear; to explain, to understand` → `明亮，清晰；解释，明白`
3. **保留变体/正字信息**：如 `variant of 考` → `「考」的异体字`；`old form of 某` → `「某」的古字`。
4. **人名地名**：如 `surname` → `姓`；`name of a river` → `古水名`；不译音。
5. **简练**：每个义项尽量在 2-6 个字内；总长控制在原文 1.5 倍以内。
6. **h 字段**（词源提示）：翻译成一句中文白话（原文如 `The light of the sun 日 and moon 月` → `太阳（日）和月亮（月）的光`），保留其中的汉字；若 h 为空则留空字符串。
7. **不编造**：拿不准的义项照实直译，不要补写英文里没有的意思。

## 输出格式示例

输入：
```json
{
  "明": { "d": "", "h": "" },
  "考": { "d": "", "h": "" }
}
```
输出（写入同一文件）：
```json
{
  "明": { "d": "明亮，清晰；解释，明白", "h": "太阳（日）和月亮（月）的光" },
  "考": { "d": "「考」的异体字", "h": "" }
}
```

完成后报告：共填写 X 条，其中 d 为空 Y 条。
